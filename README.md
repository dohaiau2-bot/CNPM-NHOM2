# ***Mục tiêu***

Xây dựng một hệ thống quản lý mượn – trả sách thư viện giúp tự động hóa quy trình quản lý bạn đọc, sách, và quá trình mượn/trả, tăng hiệu quả và tiện lợi cho thư viện trường đại học sư phạm.

# ***Công nghệ sử dụng***

**Framework**: Flask (Python) cho phần backend

**Frontend**: HTML, CSS, JavaScript để tạo giao diện người dùng thân thiện

**Backend**: Python xử lý nghiệp vụ, kết nối cơ sở dữ liệu

**API**: Thiết kế RESTful API cho phép các thành viên và ứng dụng khác có thể gọi và tương tác với hệ thống

**Công cụ kiểm thử API**: Postman dùng để kiểm tra và chạy thử các endpoint của API

**Quản lý mã nguồn**: GitHub, có README hướng dẫn chạy và test API
